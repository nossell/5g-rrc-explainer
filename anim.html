流程动画资产库

每件动画都是自绘矢量（SVG）+ 自写脚本的私有资产：同一个动画引擎（时间轴/节拍/字幕/跳转），配上不同流程的"道具剧本"。现有三件——接入、切换、掉线救场——后续按模块持续追加。

01 · 接入全流程（注册 / Attach）

九拍讲完一场"落户"：喊一嗓子 → 空中握手 → 捎带信件 → 验身 → 交钥匙 → 上锁 → 登记能力 → 装网卡 → 在线。点进度点可跳任意节拍。

进入第一课（逐帧交互版） 回到导读页

02 · 切换全流程（XN 站间）

十二拍讲完一场"搬家"：侦察报告 → 托运备房 → 搬家命令（T304 沙漏）→ 断旧迎新 → 交接账本 → 新家签收 → 数据改道 → 源站销户。源熄新明的全过程一镜到底。

进入切换课（四场景交互版） T304/T316 定时器对照

03 · 掉线救场（RLF 与 RRC 重建）

八拍讲一场"断线自救"：连续失步（N310）→ T310 到期宣布失败 → 三件套求救信（C-RNTI+PCI+shortMAC-I 防伪章）→ 档案找回 → 链路重生续传。救场不成才回 IDLE。

切换课 · 失败幕与重建请求 INACTIVE 课 · 恢复三件套对照
